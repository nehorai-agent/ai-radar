01Neon AI Gateway: כל המודלים נפתחים למנוי בתשלום עם prepaid credits+

מה אומת

ב-changelog של Neon מ-9.10 נאמר שאין צורך יותר בבקשת גישה למודלי frontier: כל המודלים בקטלוג פתוחים לחשבון בתוכנית בתשלום שיש לו prepaid credits. נוסף גם Claude Opus 5.5. זה אינו גישה חינם, ואינו כלל שמספיק להיות מנוי בתשלום בלי יתרה.

ה-quickstart הנוכחי מונה אזורי AWS Ohio, N. Virginia, Frankfurt ו-Singapore. לא כל אזור זמין. gateway מרכז קריאות לספקים, אבל הוא לא מבטיח שכל פרמטר או יכולת של מודל נתמכים באותה צורה. לפני שימוש צריך לבדוק model ID ויכולות בקטלוג, לא להסיק מהשם בלבד.

השינוי השימושי יותר ב-CLI

neon deploy ו-config apply שואלים לפני פעולה על branch מוגן או החלפת הגדרות קיימות. בלי terminal הם עוצרים, אלא אם הועברו flags מפורשים או yes לשניהם. עוד שינוי: neon me אומר באיזה credential משתמשים בלי לפתוח login לבד, ו-orgs list מסמן את הארגון המקושר לתיקייה. אלה הגנות מפני פעולה בחשבון או branch לא נכונים.

skills למוצרים ו-send_feedback ב-MCP/CLI מוזכרים גם הם. Neon אומרת שב-feedback נשלח רק הטקסט, בלי פרטי חשבון או connection. זה אינו מסנן secrets מהטקסט שאתה כותב. הדוגמאות להתקנת skills ולמחיקה לילית הן tutorial, לא הוראה להפעיל אותן.

החיבור אליך: אם מענה או podcasto כבר משתמשים ב-Neon, שווה לבדוק אם gateway מפשט את הגישה למודל שאתה בוחן. אין לי ראיה לכך, ולכן אין המלצה להעביר backend או לקנות credits. העיקרון שכדאי לקחת גם למערכת שלך: deployment לא אינטראקטיבי צריך להיעצר כשלא ברור אם היעד מוגן או אם config קיים עומד להשתנות.

הסתייגות

לא נפתח חשבון ולא נרכש credit. לא בדקתי מחיר לכל מודל, latency או תנאי retention; לכן לא מוצגת השוואת ספקים. סעיף אחסון Free מהניוזלטר לא נחשב השקה חדשה ולא נכלל.

02Claude Code 2.1.296: MCP כבוי נשאר כבוי, ועלות ה-cache מתיישרת למחיר החדש+

מה השתנה

הגרסה פורסמה ב-9.10 ב-19:28 UTC. תוקן headless session שהפעיל שרת MCP מפרויקט או plugin למרות שהיה כבוי עבור התיקייה, אחרי cd או reload. תוקנו managed PreToolUse hooks עם continue:false ו-prompt hooks שחסמו פעולה אבל לא סיימו את התור. PostToolUse מחיל כעת updatedMCPToolOutput גם במסלולים שבהם נשמט.

עלות והקשר

cost, status line, max-budget-usd ונתוני עלות SDK עודכנו לקריאות cache של Sonnet 5.5 ב-$0.10 למיליון, במקום $0.20. זה יישור כלי המדידה לשינוי המחיר שהוכרז ב-7.10, לא הנחה חדשה היום. תוקן גם token counting ל-Haiku 5.5 ומודלי adaptive thinking מאחורי gateways. לתתי-סוכנים נוסף autoCompactWindow, ואפשר לקבוע מודל אחד לכל workflow agents בלי לשנות אחרים.

תיקונים שלא רואים בדמו

secret redaction ב-debug logs וב-transcripts משותפים תוקן עבור חלק מהערכים שהופיעו אחרי key ללא value, כולל JSON בתוך shell string. עריכת קובץ שאינו UTF-8 תקין כבר נדחית במקום להחליף תווים לא-ASCII; חשוב לקבצים ב-Windows-1252, Shift-JIS או GBK. תוקן גם restart שחזר על turn שכבר הסתיים בתוצאת כלי MCP, והרצה כפולה של prompt בעת מעבר לרקע.

החיבור אליך: אם יש שרת MCP שכבית בפרויקט של podcasto או מענה, בדוק בתיקייה זמנית שהוא נשאר כבוי אחרי שינוי directory או reload. בדוק גם שסכומי cost תואמים לנתוני usage אחרי שינוי המחיר. redaction משופר אינו סיבה לשתף debug log בלי קריאה ידנית, במיוחד כשהוא מכיל config או פלט shell.

הסתייגות

כל release notes נקראו, אך הגרסה לא הורצה והתקלות לא שוחזרו. אין ב-notes מיפוי מלא לגרסאות מושפעות או הוכחה לדליפה בפועל. התיקון למחיר אינו מקטין usage limits במנוי.
